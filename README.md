# Pathology LLM Data Extraction - Thyroid Cancer Pilot

This project tests the generalizability of Large Language Models (LLMs) in extracting structured data from thyroid cancer pathology reports.

## Structure

```
pathology-llm-data-extraction/
├── data/
│   ├── raw/                  # Original GDC download folders and PDFs
│   ├── parsed_reports/       # Markdown files generated by LlamaParse
│   └── gold_standard/        # thyroid_gold_standard.csv (Ground Truth)
├── src/
│   ├── extract_gold_standard.py # Initial script to create gold standard from XML
│   ├── verify_thca_data.py      # Script to verify data integrity
│   ├── preprocess_pdfs.py       # Converts PDFs to Markdown using LlamaParse
│   ├── run_inference.py         # Runs models on parsed reports via OpenRouter
│   └── analyze_models.py        # Calculates accuracy metrics
├── output/
│   └── inference_logs/       # Results: model_outputs.csv
├── requirements.txt
└── README.md
```

## Setup

1.  **Install Dependencies**:

    ```bash
    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
    ```

2.  **Environment Variables**:
    Create a `.env` file with:
    ```
    OPENROUTER_API_KEY=sk-or-v1-...
    LLAMA_CLOUD_API_KEY=llx-...
    ```

## Workflow

### 1. Preprocessing (PDF -> Markdown)

Converts the noisy PDF scans into clean Markdown text using LlamaParse.

```bash
python src/preprocess_pdfs.py
```

_Note: This processes all PDFs linked in the gold standard CSV. It skips already parsed files._

### 2. Inference (Markdown -> JSON)

Runs the configured LLMs (Mistral Large, Llama 3.1 405B, etc.) on the parsed reports.

```bash
python src/run_inference.py
```

_Note: This appends results to `output/inference_logs/model_outputs.csv`._

### 3. Analysis

Compares the model outputs against the gold standard and generates metrics.

```bash
python src/analyze_models.py
```

## Models Tested

- **Large**: Mistral Large 2, Llama 3.1 405B
- **Medium**: Llama 3.1 70B, Mixtral 8x7B
- **Small**: Llama 3.1 8B, Mistral 7B
